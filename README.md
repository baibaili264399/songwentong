## 一、如何运行

方式一（最简单）：双击 `index.html`，或双击 `打开游戏.bat`。
方式二（推荐，存储最稳）：在本目录起一个静态服务器，例如

```powershell
python -m http.server 8123
# 然后浏览器打开 http://127.0.0.1:8123/
```

> 存档使用浏览器 `localStorage`。直接双击打开（file://）时主流浏览器同样可用；
> 若浏览器禁用了本地存储，页面会自动退回"内存存储"并在右下角提示"仅当前会话"。

## 一之二、手机端（重点）

打开 https://baibaili264399.github.io/songwentong/ 即可，已针对手机做了这些处理：

| 能力 | 说明 |
|------|------|
| **自动横屏全屏** | 在启动屏「点击画面开始」那一下（浏览器的用户手势要求）自动 `requestFullscreen()` + `screen.orientation.lock('landscape')`。**Android Chrome / Edge 会直接转成横屏全屏** |
| **添加主屏幕即横屏** | `manifest.json` 里写了 `"orientation": "landscape"` 与 `"display": "standalone"`，Android 添加到主屏幕后，点图标启动就是横屏全屏、无浏览器地址栏 |
| **iPhone（iOS Safari）** | Safari 不支持元素全屏与方向锁定，因此竖屏时会弹出「请把手机横过来」覆盖层，点按钮重试全屏、或手动横过来；想彻底全屏请用「分享 → 添加到主屏幕」 |
| **竖屏兜底** | 竖屏时显示旋转提示覆盖层，也可点「仍然竖屏继续」降级游玩 |
| **触屏适配** | `body.is-touch` 下整体放大字号与热区：手机横屏（844×390）实测菜单字号 16.6px、热区 198×38px、对话正文 16.6px；菜单改成双列、存档位改单列大行、删除按钮常显（手机没有 hover） |
| **防误操作** | 禁用双击缩放、下拉刷新、长按选中与长按菜单；`dvh` 动态视口高度避免地址栏导致舞台算高被裁 |
| **刘海屏** | `viewport-fit=cover` + `env(safe-area-inset-*)` 安全区内缩 |

> 舞台是 16:9，宽屏手机（19.5:9）左右会有黑边——这是刻意的：改成铺满会裁掉底部对话框。

## 三、本版本已实现

**标题屏**
- 标题 LOGO、氛围粒子背景、占位立绘（呼吸动画 + 鼠标视差 + 柔光遮罩）
- 菜单：开始游戏 / 继续游戏 / 读取存档 / 存档管理 / 游戏设置 / 关于本作
- 「继续游戏」自动显示最近存档，无存档时置灰不可点
- 键盘：`↑ ↓` 选择、`Enter` 确认、`Esc` 返回；鼠标悬停/点击有合成音效
- 首次进入有"点击画面开始"启动屏（同时用于解锁浏览器音频）

**存档系统**
- 1 个自动存档位 + 1 个快速存档位 + 6 个手动存档位，`localStorage` 持久化
- 每个存档位记录：章节 id、剧情步号、当前台词、句序进度、游玩时长、保存时间
- 三种模式：存档（可覆盖，覆盖前二次确认）、读档、存档管理（展开详情 / 删除）
- 自动存档时机：进入章节、返回标题、游戏中每 45 秒；可在设置中关闭
- 「清空全部存档」带二次确认

**设置**
- 文字速度（0-100，100 = 瞬间显示，实时影响对话逐字演出）
- 音效音量 / 启用交互音效（音效由 WebAudio 实时合成，无需音频素材，可试听）
- 背景音乐音量通道（预留，素材待接入，当前置灰）
- 自动存档开关、全屏切换、恢复默认设置

**剧情演出（VN）**
- 版式：全屏背景 + 角色立绘层 + 底部对话框（名牌 + 正文）+ 右侧竖排「回想 / 自动 / 跳过 / 设置」+ 底部「快读 / 快存 / 读档 / 存档 / 记录 / 标题」+ 左右翻页箭头（按钮小字为对应的英文原词，保留参考图那种味道）
- 背景双层交叉淡入，支持缓慢横移镜头（Ken Burns）
- CG 特写层（内嵌 / 全屏两种模式，支持缓慢推近）
- 台词类型分色：内心独白 / 内心震动 / 低声说话 / 旁白动作 / 记忆闪回
- 演出特效：白闪、震屏、BUG 乱码（世界修正力伏笔）、记忆闪回去色压暗、画面边缘微光
- 章节卡：单独停留 2 秒再进正文；章节结束有「待续」卡，点击返回标题
- 自动播放（读完停顿后自动推进）、跳过、回想（重播当前句）、剧情记录 LOG
- 键盘：`Enter`/`空格`/`→` 推进，`←` 上一句，`S` 存档，`L` 读档，`A` 自动，`K` 跳过，`H` 记录，`Esc` 返回标题

**手机端**
- 触屏识别（`pointer: coarse` / `ontouchstart` / `maxTouchPoints`）→ `body.is-touch`
- 首次点击自动全屏 + 锁定横屏；支持 PWA 添加到主屏幕后横屏启动
- 竖屏旋转提示层（含"仍然竖屏继续"降级）、双击缩放与下拉刷新屏蔽、安全区适配
- 剧情屏在手机上整体放大：对话框、右侧按钮、底部按钮、箭头都是可点热区

## 四、开发锚点（调试用，追加在 URL 后）

| 锚点 | 效果 |
|------|------|
| `#skipboot` | 直接进入标题屏（跳过启动屏，用于截图） |
| `#game` | 直接进入占位剧情屏 |
| `#save` / `#load` / `#manage` | 直接打开对应存档面板 |
| `#settings` / `#about` | 直接打开设置 / 关于面板 |
| `#selftest` | 端到端自检（存档写入、读取、删除、最近存档判定、设置持久化），结果写入 `body[data-selftest]` |
| `#measure` | 布局量测：把关键元素的实际宽高/位置/字号写进 `body[data-measure]` |
| `#stepN` | 直接跳到第一章第 N 步（截图某一幕用），例如 `#step21` 是手机屏幕特写 |
| `#log` | 直接进章节并打开剧情记录面板 |
| `#mobile` / `#desktop` | 强制触屏 / 桌面环境，用来在电脑上预览手机版布局 |
| `#fit` | 把舞台钉成固定 880px 宽，便于在任意窗口里截手机版布局图 |

锚点可以用 `-` 组合，例如 `#mobile-fit-game`＝手机布局 + 固定舞台 + 直接进剧情屏。

命令行自检示例：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --dump-dom `
  "file:///C:/Users/陆世松/Desktop/错位夜宵/index.html#selftest"
```

> 无头截图小坑：Edge `--headless=new` 的 `--window-size` 是**窗口**尺寸，
> 实际排版视口约为「宽 −30、高 −95」，宽度下限 504px。
> 想截 844×390 的手机横屏效果，要传 `--window-size=874,485`，否则会按更小的视口排版、截图右侧被裁。

## 五、存档数据结构

```jsonc
// localStorage key: gal.saves.v1
{
  "auto": {
    "slot": "auto", "seq": 12,
    "chapterId": "ch1", "step": 17, "kind": "narration",
    "chapter": "第一章 · 醒在别人的身体里",
    "speaker": "", "text": "【屏幕特写】白天的日期与时间……",
    "line": 9, "total": 17, "progress": 0.53,
    "playtime": 96, "scene": "ch1",
    "savedAt": 1750000000000, "createdAt": 1750000000000, "playCount": 1
  },
  "quick": { "...": "快速存档，结构相同" },
  "1": { "...": "手动存档，结构相同" }
}
// localStorage key: gal.settings.v1
{ "textSpeed": 55, "sfxVolume": 60, "sfxEnabled": true, "bgmVolume": 40, "autoSave": true }
```

> 读档时按 `chapterId` + `step` 精确回到那一句：引擎会先把该步之前的背景 / CG / 特效
> 静默重放一遍，再从该句继续，所以读档后的画面和存档时一致。
