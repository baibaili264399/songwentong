# 《错位夜宵》设定集（v0.1 · 记录用，持续更新）

> 本文件用于"记住"你到目前为止敲定的全部设定。做后续内容时以本文件为准。

## 一、项目定位

- 类型：Galgame（AVG 视觉小说），无 H、校园向。
- 参考基调：《重生萝莉岛》式的校园日常 + 命运救赎分支。
- 舞台：一所综合性大学（大学学院背景：教室、走廊、图书馆、计算中心、体育场、大礼堂、宿舍、食堂、小卖部、雷锋雕像下、健身楼、校内石桥等）。
- 三男主可攻略（稀缺 / 独特 / 小众吃香）+ 一条回归现实真结局线。
- 引擎形态：先做 Web 版原型（HTML/CSS/JS），主菜单 → 存档系统 → 章节剧情逐层扩展。

## 二、一句话梗概

男主（玩家）熬夜通关了一款小众治愈系 Galgame，饿到极点，用仅剩的 11.30 元点了一份 9.9 元拼好饭炸鸡；
吃下第一口时剧烈耳鸣、眩晕倒地，再睁眼已**附身到那款游戏的原作男主身上**——
他带着"全剧情攻略记忆"和"现实记忆"，成为唯一知晓所有人既定悲剧的"外来者"。

## 三、世界观 & 核心前提（已敲定）

1. **男主身份**：直接附身到原作游戏里面的男主身上（占据原主角身体）。两套记忆并存 → 天然"外来者的割裂感"。
2. **那个外卖（核心伏笔）**：【物品带有力量】——这份 9.9 拼好饭是**"错位时空的产物"**，并非普通外卖，是夹缝时空的裂缝。后期慢慢揭开谜底，最终"再次找到同款 / 时空错位食物源头"即可回家。
3. **记忆规则（定死）**：
   - 男主：完整保留现实记忆 + 原作男主人生 + 全部剧情攻略记忆（知道谁的 BE、谁的隐藏线、哪个关键节点）。
   - 世界里的角色：完全无察觉、无预知、无穿越认知。
   - 男主**绝不能口头剧透未来**；一旦强行剧透关键命运 → 大规模世界报错。
4. **现实世界的牵绊**：双结局方向（回归现实 TRUE END / 留在异世界 STAY END）。
5. **世界意志**：这个 GAL 世界不是虚拟数据，而是**半真实半次元的夹缝世界**；那次 9.9 错位外卖是世界意志故意投放的时空漏洞。
   - 为什么选男主：他完美通关全结局、看懂所有人的悲剧与温柔——世界意志想让"一个真正懂他们的人"来改写所有人的既定悲剧。
   - 世界意志规则：① 不能直接说话、不能剧透、不能干预选择；② 只能通过【BUG 震荡 / 好感反馈 / 梦境碎片】暗示男主；③ 改剧情太多 → 世界崩坏风险；④ 男主随时可以找到「错位外卖原点」回归现实。

## 四、系统设定（最适合 GAL 的极简温柔系统）

1. **隐性好感度可视**（不弹窗霸屏、不任务绑架）：视线落在可攻略角色身上时，心底自动浮现模糊好感数值，只有男主看得见。
   `0 陌生 → 20 眼熟 → 40 友好 → 60 在意 → 80 偏爱 → 100 唯一`
2. **剧情修正预警**：大幅篡改原作剧情 / 拯救 BE / 改变关键节点时，视野边缘轻微闪烁 BUG 乱码、空气微震、耳鸣，提示【世界修正力启动，剧情偏移过大】。
   - 轻微干预 → 视野边缘乱码闪烁、轻微空间震荡；
   - 危机（后期）：继续强行改写命运 → 整个游戏世界有崩坏消失的风险。
3. **代价机制（高潮冲突）**：回去的通道不是永久关闭，开启条件与当初那份错位外卖有关；
   但**打开通道的代价**：一旦回去，游戏世界里所有人连同这段相处的记忆，会从男主脑海慢慢淡化遗忘。
4. **双结局锁死**：
   - **TRUE END【回归现实】**：找到时空裂缝，斩断世界绑定，醒来回到出租屋地板；炸鸡倒扣在地、电脑停在通关界面、"仿佛大梦一场"，但心底永远残留三人的痕迹。留白：外卖平台永久残留一条无法删除的 9.9 元订单 / 已经下架的套餐记录。
   - **STAY END【留下】**：主动放弃回归通道，承受世界修正的反噬，彻底打破原作命运，救赎所选角色，达成专属甜蜜结局；代价是世界持续震荡。
   - 另有三个角色各自的 **Bad End**（男主处理不当 → 角色走向内心封闭、彻底逃避自我的悲剧）。

## 五、角色（三名可攻略）

### 角色① 郑桐（桐桐 / 22 岁 / 大三 / 社会学专业）
- 设定：幼年被拐卖后解救；受过创伤，渴求"选择权"。外表随和，内心始终保留安全距离；擅长察言观色，压力下会突然抽离、切断关系；睡觉房门习惯留缝；随身背包挂起毛的红色平安福荷包。
- 出没地点：雷锋雕像下（独自坐着发呆）、图书馆靠窗阅览区（下意识扫视四周确认出口）、湖边石桥（黄昏吹风）、食堂。
- 关键剧情触发点：
  1. 【走廊事件】下课走廊被同学起哄强行安排集体出行、要求不许缺席，表面笑着答应但身体紧绷；男主察觉悄悄解围 → 轻微世界震荡（第一次小 BUG 预警），好感上升。
  2. 【雷锋像下夜谈】黄昏陪坐，不逼他倾诉创伤，慢慢聊，才隐约流露对"选择权"的执念。
  3. 【石桥雨夜】下雨的校内石桥 = 情绪崩溃节点，桐桐个人线重要转折点。

### 角色② 江灼（小灼 / 21 岁 / 大二 / 新闻传播专业）
- 双重人格：【灼】厌世傲娇、爱吃甜食、内心渴望可以托付的人、刀子嘴豆腐心；【阿火】热情奔放爱往外跑、抗拒恋爱。两人格互相知晓内心想法，随机无预兆切换。
- 出没地点：体育场看台、小卖部、健身楼、大礼堂后台。
  - 阿火：精力旺盛，看台看球、健身楼简单锻炼、小卖部疯狂买甜食、大礼堂晚会后台凑热闹。
  - 灼：嫌吵闹，独躲体育场偏僻上层看台，一个人默默吃糖，不希望被打扰。
- 关键剧情触发点：
  1. 【小卖部冲突事件】货架前拿焦糖糖果时毫无征兆人格切换（前一秒嫌弃幼稚 → 下一秒眼睛发亮兴致勃勃），男主恰好撞见 = 初遇名场面。
  2. 【健身楼休息区】灼身心疲惫、嘴硬不承认希望有人依靠；选耐心陪伴，不逼他敞开心扉。
  3. 【大礼堂晚会后台】嘈杂喧闹 + 巨大压力诱发频繁人格切换 = 江灼线高潮节点，必须学会同时接纳两个人格，不能只偏爱其中一方。

### 角色③ 阿松（20 岁 / 大二 / 计算机科学系）
- 社恐"电子幽灵"：喜欢在宿舍穿漂亮小裙子自拍（只宿舍内，绝不外穿）；深度宅；收藏旧物件；网上非常活跃，现实尽量回避社交；害怕线下碰面；爱吃炸鸡可乐，讨厌饼干糕点。
- 出没地点：计算中心机房（必修课上机）、宿舍、深夜的食堂、图书馆最偏僻角落；几乎不去体育场 / 大礼堂等人多喧闹场所。深夜食堂人少时才敢下楼买炸鸡与冰可乐。
- 关键剧情触发点：
  1. 【计算中心机房初遇】缩在最靠角落的机位低头降低存在感，男主意外发现他在偷偷浏览二手老物件收藏网页。
  2. 【宿舍线上秘密】只能先靠网络聊天慢慢拉近距离；**贸然上门会直接惊吓到他 → 绝对禁止直接敲他宿舍门（本线巨雷区）**。
  3. 【深夜食堂偶遇】寥寥几人的深夜食堂，独自买炸鸡与冰可乐，是现实里难得能简短交谈的机会，不要强行攀谈；个人线后期才慢慢鼓起勇气愿意短暂散步（最远走到安静的湖边小桥，避开人流）。

> 备用设定（二选一，倾向后者）：桐桐 / 江灼 / 阿松**并非原作里的角色**——因为男主的闯入、世界线发生偏移才诞生了这三位少年；或者他们本就是原作的可攻略人物。

## 七、剧情推进结构

- **序章（已写好 · 见 `docs/序章脚本.md`）**：深夜 02:17 → 通关 → 11.30 元 → 9.9 拼好饭 → 黑屏转场 → 取外卖 → 第一口 → 耳鸣眩晕 → 黑屏【穿越完成】→ 睁眼在大学宿舍床上，两套记忆疯狂对冲。
- **第一阶段【校园日常，第 1-4 章】懵懂代入**：适应世界 + 依次邂逅三人。
  确认穿越、拥有上帝视角 → 发现自己能看见好感、能感知世界 BUG → 依次偶遇桐桐（走廊）/ 江灼（小卖部人格切换）/ 阿松（机房）。初期心态：只想回家、不敢乱改剧情、怕世界崩。
- **第二阶段【试探救赎，第 5-9 章】**：第一次干预剧情、第一次触发世界 BUG。
  忍不住出手阻止三人的 BE 命运：悄悄改变桐桐的某次二次伤害事件、温柔接住江灼人格切换的情绪低谷、线上匿名治愈孤独的阿松。
  每一次救赎都轻微引发世界震荡 → 男主意识到"我救人，是要付出代价的"。心态分裂：一边想回家，一边舍不得三个满身遗憾的少年。
- **第三阶段【真相浮现，第 10-13 章】**：揭秘错位外卖真相（梦境碎片 = 世界意志暗示）。
  ① 9.9 拼好饭是时空裂缝产物；② 这个世界所有角色原本都是注定悲剧结局；③ 男主是唯一通关者、唯一能拯救所有人的"外乡人"；④ 只要再次找到「时空错位食物源头」就能回家。
  代价浮出水面：回家 = 这个世界所有被你改变的温柔全部归零，所有人回归原本悲剧命运、遗忘所有救赎。
  校园开始频繁 BUG：走廊灯光疯狂闪烁、图书馆书本页码错乱、体育场时钟偶尔倒走。
- **终章抉择（第四阶段）**：TRUE END【回归现实】 / STAY END【留守救赎】。

## 八、风格约束（对齐《重生萝莉岛》）

- 无 H，侧重校园日常 + 心理描写 + 命运抉择；没有血腥；重点写人物内心挣扎。
- 校园场景必须充分利用起来，不要只当背景板。
- 世界观是"改剧情会 BUG"的硬核设定，可用来制造危机与张力。
