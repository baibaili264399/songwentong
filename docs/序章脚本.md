# 序章 · 错位夜宵（正式脚本）

> 类型：游戏开篇脚本（叙事 + 镜头 + 台词 + 旁白）。可直接作为演出文本使用。
> 风格约束：无 H、无血腥，侧重日常质感与心理描写。

## 【Opening · 氛围】

室内，主角的卧室，深夜。荧光的电脑屏幕是主要光源，环境很安静，只有机箱风扇微弱嗡鸣。
- 背景 BGM：低沉舒缓的深夜电子氛围音
- 画面：显示器上是通关结局 CG，通关字幕缓缓滚动

**主角（内心独白）**：终于……通关了。熬到这么晚。

**动作描写**：主角向后靠在电竞椅上，长长伸一个懒腰，骨头轻微发出咔咔的声响。揉了揉酸涩的眼睛。肚子"咕——"地响了一声。

**主角（小声自语）**：好饿，想吃点东西。

## 【场景：钱包余额】

- CG 镜头：主角拿起手机，屏幕亮起。钱包余额界面特写 —— **余额：11.30 元**

**主角（叹气，内心 OS）**：就剩这点钱了……晚上不能点贵的。

主角点开外卖软件，滑动浏览。镜头给到手机屏幕，定格在【拼好饭 · 9.9 元炸鸡套餐】。

**主角**：行吧，就这个。

（点击下单。画面慢慢变黑，黑屏转场，跳过外卖等待的几十分钟。BGM 短暂消失。）

## 【场景：深夜楼道取餐】

黑屏淡出，重新亮回画面。楼道的手机手电筒微弱光影，主角穿着拖鞋下楼拿外卖。
（音效：脚步声；塑料袋沙沙声。主角接过外卖，转身快步回到自己的卧室，关上房门。）

主角撕开外卖包装，迫不及待咬下一大口炸鸡。

**音效**：咀嚼声。接下来骤然出现一阵诡异的耳鸣嗡声（SFX：耳鸣嗡——！）

主角瞳孔猛地放大，面部出现眩晕、恍惚的表情。

**主角（短促失声）**：啊……！

（身体失去支撑，重重摔倒在地！手机从口袋滑出，炸鸡盒子倒扣。画面迅速旋转、色彩撕裂扭曲，视野彻底陷入黑暗。）

【意识黑屏。穿越完成。】

## 【场景：醒来 · 大学宿舍】

短暂黑暗后。

温柔的光、微风、树叶沙沙声，缓慢填满视野。

主角猛地睁眼、大口喘气。

映入眼帘的不是自己的出租屋，是干净整洁、带着日系清新风格的少年卧室，窗外晴空、远处校园钟楼。

脑袋剧痛。

**两段记忆疯狂对冲 ——**
- 【现实熬夜通关的自己】
- 【这款 Galgame 原生主角的人生：日常、身份、班级、人际关系】

他僵在床上，浑身发麻。

**主角（内心震炸裂）**：
不是做梦……
我附身到**我刚刚通关的 Galgame 的原作主角身上**了？！
